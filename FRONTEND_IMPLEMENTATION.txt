3. public/app.js (12 KB, 323 lines)

   Four Alpine components plus store:

   STORE: Alpine.store('app')
   - summary object: done, in_progress, not_started, total, completion_percent, total_time_spent
   - async refreshSummary() fetches /api/stats/summary

   COMPONENT: appShell()
   - State: page, loading, labs[], filterCat, search, categories[]
   - Getter: summary (reads from store)
   - init() loads labs, listens to refresh-labs event
   - fetchLabs() fetches /api/labs, updates summary
   - get filteredLabs() filters by category and search
   - formatTotalTime(s) returns h format or m format

   COMPONENT: labCard(initialLab)
   - init() reads open_session_started_at, resumes if elapsed < 8h
   - startTimer() creates open session, starts interval
   - stopTimer() closes session, calls await Alpine.store("app").refreshSummary()
   - resetTimer() clears state
   - updateStatus() sends status, calls await Alpine.store("app").refreshSummary()
   - launch() opens Packet Tracer with error handling
   - showToast(msg) displays for 3.5 seconds
   - formatTime(s) returns HH:MM:SS
   - statusLabel(), badgeClass(), cardClass() helpers

   COMPONENT: importPage()
   - loadStatus() fetches /api/import/status
   - handleDrop(e) and handleFileInput(e) process files
   - uploadFiles(files) posts to /api/import/upload with FormData
   - scanFolder() posts to /api/import/scan with folder path

   COMPONENT: statsPage()
   - summary getter reads from store (auto-updates)
   - async load() fetches data, sets loading=false, awaits $nextTick(), renders chart
   - renderChart(data) creates Chart.js bar chart
   - formatTime(s) returns h format or m format
