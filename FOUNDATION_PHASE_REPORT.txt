DATABASE SCHEMA
================================================================================

Three tables with proper relationships:

labs
----
id (TEXT PRIMARY KEY)
name (TEXT NOT NULL)
category (TEXT NOT NULL)
file_path (TEXT DEFAULT NULL)

progress
--------
lab_id (TEXT PRIMARY KEY) - Foreign key to labs
status (TEXT DEFAULT 'not_started') - CHECK constraint
time_spent (INTEGER DEFAULT 0)
last_opened (TEXT DEFAULT NULL)

attempts
--------
id (INTEGER PRIMARY KEY AUTOINCREMENT)
lab_id (TEXT NOT NULL) - Foreign key to labs
started_at (TEXT NOT NULL)
duration (INTEGER DEFAULT NULL) - NULL = open session

APPLICATION STARTUP

1. Startup Handler executes:
   - Creates labs_files/ directory
   - Initializes database (creates labs.db if needed)
   - Cleans zombie sessions (DELETE FROM attempts WHERE duration IS NULL)
   - Seeds 51 labs if database empty

2. Server starts on 127.0.0.1:8080

3. Registers 5 routers for API endpoints

4. On Ctrl+C:
   - Shutdown handler executes
   - Closes database connection gracefully
   - Server stops

CRITICAL IMPLEMENTATION NOTES
================================================================================

1. Zombie Timer Cleanup
   - Placement: AFTER executescript, BEFORE checking lab count
   - Purpose: Delete attempts rows with duration=NULL (crashed sessions)
   - Prevents multi-day timer resume bug

2. Empty __init__.py Files
   - CRITICAL: Without these, Python raises ModuleNotFoundError
   - Must exist: routers/, services/, database/, models/

3. PT_EXE Validation
   - On startup, checks if Path(PT_EXE).exists()
   - If missing: prints yellow warning, continues
   - If present: silent
   - Allows browsing progress even without Packet Tracer installed

4. No CORS Middleware
   - Same-origin app (browser and server at localhost:8080)
   - CORS headers not needed
   - Omitting CORS makes debugging clearer

5. Async Database
   - All database calls are awaitable (await db.execute(...))
   - Never use sync sqlite3 module
   - Prevents blocking Robyn's event loop

6. Pydantic v2
   - model_validate() not parse_obj()
   - field_validator not validator
   - Literal type for enums
   - Required by specification
